# SSD Ekomart — Grocery Store Website

A grocery e-commerce website concept designed to present an online grocery shopping experience with product-focused layouts and store information.

## Live Demo

[View the live website](https://mkaceduet-hub.github.io/grocery-ssd-ekomart/)

## Project Overview

SSD Ekomart is a front-end portfolio project in the grocery and online retail category. The repository includes the main HTML page and supporting assets, styles, and scripts.

## Technologies

- HTML5
- CSS3 / SCSS
- Bootstrap
- JavaScript

## Getting Started

1. Clone or download this repository.
2. Keep the included `assets` folder in its original location.
3. Open `index.html` in a modern web browser.

## Important Note

This repository demonstrates a front-end shopping interface. A production store requires secure product, cart, checkout, payment, and order-management services. Product and price information should be verified before use.
